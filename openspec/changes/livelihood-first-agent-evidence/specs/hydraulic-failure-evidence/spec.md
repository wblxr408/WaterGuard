# Spec Delta

## Purpose

让 Agnes 的方案修订基于已验证的水力事实，而不只是拓扑邻近排序；这些事实来自原始仿真结果，不是预测。

## ADDED Requirements

### Requirement: 设施作用证据
诊断 SHALL 在失败窗口内，根据原始管段流量为每个允许设施给出平均流量、流向，以及沿该流向其下游失效节点的数量和占失效需求的比例，并标出其是否位于通向故障点的供水路径上。证据 SHALL 仅由已独立复算的失败报告对应的原始结果得出，并声明为观测而非收益预测。

#### Scenario: 位于失效区上游
- **WHEN** 某设施的流向通过其下游抵达若干失效节点
- **THEN** 诊断给出这些节点的数量和需求占比

#### Scenario: 供给故障点
- **WHEN** 某设施的流向可达故障点
- **THEN** 诊断标出该设施位于故障供水路径

#### Scenario: 无流量
- **WHEN** 设施在窗口内无流量
- **THEN** 其下游影响为零，并排在有影响的设施之后

### Requirement: 诊断确定性与边界
同一失败报告和原始结果 SHALL 得到相同诊断。诊断 SHALL NOT 放宽权限、改变设施许可集合或给出通过结论。

#### Scenario: 重复读取
- **WHEN** 对同一失败运行两次读取诊断
- **THEN** 结果一致
