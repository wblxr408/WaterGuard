# Proposal

## Why

真实响应延迟下，仍有违规的改善方案具有应急交付价值。当前负结果未将这种价值作为正式交付，同时实验评分偏离冻结的逐节点目标。

## What Changes

- 增加正式结果 BEST_EFFORT_MITIGATION，保留推荐门槛、违规证据和独立推荐标志。
- 扩展有界确定性候选，覆盖多设施隔离和备用供水组合，遵守动作预算与真实延迟。
- 独立验证器输出全程达标节点数；报告逐节点基线改善和可选降级服务覆盖。
- 统一采用冻结的最差节点、平均节点、缺水量及成本排序；只声称已测范围内最优。
- 用户已于 2026-10-12 确认降级阈值 15m/75%；兼容的新任务默认冻结此附加层，显式停用时指标缺省。
- 方案对照首屏突出采用后可达到的正常/降级覆盖、相对无动作改善和剩余缺口，随当前候选同步；区分正式交付与候选仿真效果。

## Capabilities

### New Capabilities

- `emergency-mitigation`: 应急候选搜索、正式尽力挽救交付与逐节点韧性证据。

### Modified Capabilities

无。
