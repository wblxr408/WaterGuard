# Design

## Context

见 proposal.md。现有 PhysicalAdapter 提供独立求解进程、超时与取消，verify 重积分原始时序；benchmark_plans 生成受限动作，ranking_key 使用冻结排序。前端 React/TypeScript 已有同源 /wg API 和工作台候选。沿用这些模块，不重复求解器、验证器或候选生成。

## Goals / Non-Goals

**Goals:** 小型决策实验服务和完整用户入口；真实点级证据；同条件补救比较；抢修事件后重评。

**Non-Goals:** 本变更不训练大型 GNN、不迁移 AGH 框架、不新增现场控制，不把离散地图当连续鲁棒证明；需求的事件时刻突变需要新增物理契约，留在后续，当前事件支持抢修时间。按用户最新要求，本轮只交付代码，不执行验证或训练。

## Decisions

1. 增加 DecisionStudies 服务，以 RunStore 已有原子 JSON 保存 study 状态、输入、逐点评估与结论。复用单进程线程执行研究，底层仍用已隔离的 PhysicalAdapter。状态供前端轮询，避免另建队列和流协议。
2. 各变体复制 task，生成新 task_id 并重新绑定 plan。倍率是完整情景参数，抢修时刻落在原报告步长；阈值、目标和物理选项保持原口径。研究结论为 benchmark 的正常层/应急层表现，不变成 Live 推荐。
3. 基础采样覆盖分散点及状态变化邻域。用户新增要求纳入物理信息 GNN 与多保真：粗层将 hydraulic_timestep 提高到报告步长，精层保留原冻结配置；两者均使用原有引擎及独立验证。直接引用 PyTorch Geometric 的 GCNConv，构建两层32通道压力残差网络，以管道 Hazen–Williams 导水能力作为边权，输入粗解压力、节点高程/需求/度数及情景变量，训练损失包含压力拟合、PDD供水关系与图残差平滑。模型通过 MC Dropout 与训练残差表达排序不确定度，不标为校准置信区间。配对样本不足时使用粗解临界程度选点；依赖声明在 requirements-surrogate.txt，本次未安装或运行。
4. 补救输入包括提前抢修时刻或一项额外动作及成本。额外设施必须来自现有目录；有原生控制时复用准确 control_override。新权限只进入独立假设情景，不修改源任务。统一按用户声明的标量成本择优，不自动比较不同单位。
5. 事件重评从0重放相同物理历史，保留事件前动作；固定抢修事件前历史和新抢修时刻，候选只更新未来。原始全窗报告和事件后剩余时窗报告均保留。该功能不是传感器校准后的在线数字孪生。
6. 增加独立“决策实验”页面，使用 CSS 网格地图、现有字体/色板、语义按钮和详情表；支持已有工作台任务直接带入和已有研究回看。无需新图表库。
7. 低保真计算也计入 max_simulations。用户声明高精度配额，先使用其余配额粗筛，再依代理逐个选择精解并更新。地图 state 只取精解；low_fidelity、prediction、预序列预测误差和各层计数独立保存。粗步长不保证必然更快，交付实际计时而非预设加速倍数。

## Risks / Trade-offs

- 有限样本错过边界 → 展示未测点与采样数量，不填色推断。
- 物理求解失败 → 使用原有错误结果，标为 invalid，与业务缺口区分。
- 小研究预算不足遍历补救 → 只称最小已测达标成本，显示未测选项。
- 研究与真实生产推荐混淆 → 研究单独保存、关联源引用，界面称“情景研究”，不写入 source recommendation。
- 用户偏好小实现 → 不新增通用容错框架、自动重试、数据库、服务或代理训练。输入边界与原有物理契约由 Pydantic/check_task/check_plan 负责。

## Migration Plan

新增路由、页面和独立 JSON 产物，无数据库或原公共 schema 迁移。取消传递给当前求解，重启后未终态研究标为 INTERRUPTED，用户可以另开研究。既有三个角色信任边界不变；不实施新的多 Agent 委派机制，因此沿用上一轮 A2ABreak v1.0 评估，不声称本次实现了独立三 Agent。
