# 实现计划

视觉（用户复审后更新）：移除深绿侧栏，改为顶部横向导航；雾白大工作区、深蓝文字与少量钴蓝强调。以清晰字阶、横向分隔、轻边界和冷灰模型材质组织信息，主工作台突出真实拓扑，建模页突出简洁几何。
内容：工作台 → 方案对照 → 建模与仿真 → 证据中心。交互：视图入场、管网焦点与时间轴、面板/导航状态切换；尊重 prefers-reduced-motion。
技术：继承 React / TypeScript / Vite，不新增 UI/3D 依赖；SVG 实现真实拓扑与曲线；共用生成的契约类型。
步骤：严格数据适配 → 工作台与联动 → 建模与证据 → 构建与浏览器验证 → 文档和截图。
