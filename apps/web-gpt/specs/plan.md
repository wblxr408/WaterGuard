# 实现计划 · 视觉复审 v3

视觉命题：明亮的珍珠白、淡紫与暖光渐变构成全系统背景，深色文字、清透面板与少量亮蓝操作。导航、图表、列表、弹层及建模页统一采用同一视觉语言。
内容：紧凑顶栏 → 故障上下文 → 三项核心结果 / 管网 / 实体详情的统一工作面 → 准入链 → 时序与模型入口 → 验收反馈。模型页含统一光照的概念展台、两项交互示意及物理依据。
信息取舍：保留缺供体积、供需比与最低压力；操作成本、需求流量、仿真 ID 等次要信息从首屏移出，在原始详情与证据中心保留读取入口。
交互：页面轻入场、导航切换、模型入口缩放；节点/时刻/候选保持联动；尊重减少动态偏好。
实现：保留 React / TypeScript / Vite 和 API 层；重组呈现组件，完整整理样式。内置 imagegen 生成构图参考，再按页面底色、光照与留白制作生产素材；生成图不承载业务值和操作。
验证：typecheck / build；25 项交互回归；40 项布局检查，覆盖 1600 / 1440 / 768 / 390 宽度下四页无溢出、图像加载、三项指标和默认管网完整可见；查看真实截图。
