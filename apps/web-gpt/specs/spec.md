# WaterGuard 前端需求

2026-10-03，来源：完整阅读《给GPT的前端任务说明.md》。开发分支 gpt-web，独立目录 apps/web-gpt。

- 展示只读 Fixture / Benchmark，以响应头 X-WaterGuard-Mode 为依据；缺失或不一致时报错，不偷偷降级。
- 数字从 API 获取，派生值说明算法；验收完全使用 VerificationReport.admission。
- 默认真实 Net3 A/B；支持全部场景库、Fixture、候选、节点/管段、时刻和图层联动。
- 工作台：故障、指标、交互拓扑、时序、动作、五层准入、违规反馈。
- 用户补充：建模主要指 Blender，实际成果后续由 Claude 制作。本次预留展示板块并做泵站与管道剖面两个简洁交互演示，不追求花哨图片。
- 独立建模页：两项程序几何示意、可配置的 Blender 渲染成果入口；附水力模型来源、参数、实体映射、物理检查。AI 城市剖面图仅辅助说明，不代表实际模型几何。
- 证据页：查看接口可访问的真实 JSON、完整哈希和证据索引，不能伪造未开放的原始文件下载。
- 明确只读服务和 AGH 未接入；不提供假创建、执行、取消功能。
- 桌面、窄屏、键盘操作、减少动态偏好和断线错误状态。

## 验收
typecheck、build、三源浏览器联调、候选/时间/实体切换、下载、响应式与截图。原始计算不重跑、不变更公共契约。
