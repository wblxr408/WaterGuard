## 三、质感

- 字号：原样式表里 7–10px 的文字共 196 处，统一上调一档，最小 11px（正文 13px）。
- 对比度：17 处低于 4.5:1 的灰色文字加深到 `#5e6982` / `#57627a`。
- 卡片：统一圆角 14–16px、白色细边、分层阴影，可点击卡片悬停微浮。
- 去掉英文小标签（ENTITY INSPECTOR、MODEL STUDIO、EVIDENCE EXPLORER 等），改用中文短标签或删除。
- 管网：管线更粗更深，节点更大并带白描边，故障点改为红色标记和标签。
- 时间轴：加预运行斜纹、故障时段红色底纹、处置动作刻度，滑块更大。

## 四、动效

全部在 150–900ms，缓出曲线，不弹跳；系统开启「减少动画」时全部关闭（沿用 GPT 的全局规则）。

| 动效 | 表达的含义 |
|---|---|
| 切页淡入（从半透明起步，动画暂停时内容也可见） | 页面切换 |
| 导航指示条滑动 | 当前所在页面 |
| 指标数字滚动（终值永远是接口数值） | 切换方案时差值有多大 |

## 六、第二轮修改（同日）

针对三条反馈：管网图「不好点、不美观」；Blender「做得更好一点」；喷水「不好看，要更高端」。

### 管网图

- 点选不用对准细线：先找离鼠标最近的节点（15px 内），再找最近的管段（8px 内）。
- 悬停出数值卡：节点显示压力及要求、供需比、当前时段是否违规；水箱显示水位和净流入；管段显示状态、流量和流向。
- 缩放与平移：滚轮以鼠标为中心缩放（先点一下地图或按住 Ctrl 才生效，避免和页面滚动抢滚轮，地图上有提示）；拖动平移；双指捏合；放大、缩小、适应全图、定位选中、定位故障按钮；键盘方向键、+ / −、0。
- 语义缩放：放大时节点和线宽不跟着变粗；放大到一定程度自动显示节点号和管段号。
- 搜索定位：输入编号回车。同号的节点和管段用「节点 123」「管段 123」区分；只输数字时优先节点，并提示同号管段。
- 全屏查看；顶部状态胶囊统计满足、偏低、负压、无数据的节点数。
- 标签避让：故障标签和设施标签按四个方向试放，不互相压。
- 顺手修了实体详情的一个错：点管段 123 时标题显示成「节点 123」。

证据（无头 Edge，真实鼠标事件，1440×900）：

| 操作 | 结果 |
|---|---|
| 悬停节点 40 | 数值卡「压力 4.18 m（要求 ≥ 20 m）… 当前时段违规（验收报告）」 |
| 点击节点 40 | 实体详情为「节点 40」 |
| 滚轮放大 | 显示 92 个编号 |
| 拖动平移 | 选中不丢 |
| 搜索「管段 123」 | 定位到管段 123 |
| 只输「123」回车 | 定位节点 123，提示「同号管段可输入『管段 123』」 |
| 悬停管段 101 | 「开启 · 254.6 L/s（10→101）」 |

### Blender 模型 v2

- 按真实设备比例重建，细节加多：水泵（散热筋、接线盒、铭牌、风罩、联轴器护罩、轴承架、蜗壳、法兰螺栓、压力表、底座）；闸阀（环氧涂层、明杆、手轮）；储水罐（四分之一剖切、加强圈、带护笼爬梯、液位计）；清水池（格栅走道、栏杆）。
- 新增管道剖面：DN600 球墨铸铁管、承插接口与橡胶圈、水泥砂浆内衬、剖切展示、顶部爆管裂口。
- 渲染：用 Blender 自带的棚拍环境贴图给金属反射，AgX 调色；水用体积吸收显出淡蓝。
- 去掉了图片背后的淡灰矩形边。阴影捕捉器会在整片地面留下约 4% 的灰，贴到卡片上能看出图片边界。现在出图后自动减掉这层底灰，并在四周羽化，只留设备脚下的接触阴影。实测图片四角透明度从 0.045 降到 0。

### 爆管喷水

- 第一版是 9 根细水线加 260 颗散落的小水珠，像一团气泡。第二版改成十几股花瓣状水流，反馈是「不好看，要更高端」。
- 试过三种思路，都放弃了：整片透明水幕、皇冠水花，以及三种水质感（透明、影棚折射、蓝色玻璃）。正对镜头的一整片水看起来都像塑料片或玻璃板。
- 定稿：裂口斜向喷出四股粗细、角度各不相同的水弧，根部融成一股；过了最高点缩颈，断成水珠。裂口里是一道往外涌的水脊。用元球（metaball）建模，整股水是一张无缝曲面。水不投硬阴影。

### 工作台入口卡片与小屏

- 「建模展台」入口卡片换成爆管图。说明文字原来在「清水池」中间断行，现在按词组分两行。
- 旧合影图留下的偏移规则导致配图被裁：1200 / 1024 宽时右侧约 20% 被切，768 平板时一半在卡片外。已删掉旧规则，按新图重设尺寸。图注移到卡片右上角，不再压在图上。5 种宽度截图核对过。

## 七、没有验证的部分

- 没在真实投影仪、别的电脑或别的浏览器（Safari、Firefox）上看过；只用了本机 Edge 和 Claude 内置浏览器。
- 动效只确认了状态和终值正确，没有录屏逐帧看流畅度；「减少动画」只确认了样式规则存在，没在系统设置里真正打开测试。

- 没跑 GPT 的 Playwright 回归脚本（`scripts/browser-*.js`），它们依赖 GPT 本机的 npx 缓存。另外，`browser-check.js` 第 61–75 行测的是泵站 SVG 示意的视角滑块和「分解查看」按钮。两张模型卡换成渲染图后，这两个控件不再出现，这一段预计会失败，需要按新界面改写。这个脚本我没有改。
- 低配电脑上的性能没有测量。
- 管网图：双指捏合没在真实触屏设备上试过；全屏按钮没有实际测过（无头浏览器里全屏接口不可用）。
- `equipment.glb` 3.1 MB，只供下载，页面不加载；没有在别的三维软件里打开检查过。每次重跑建模脚本，GLB 的文件哈希都会变，因为元球转网格时顶点顺序不固定。几何和渲染结果不变：重渲后像素平均差 0.0006。
