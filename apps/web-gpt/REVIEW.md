## 三、质感

- 字号：原样式表里 7–10px 的文字共 196 处，统一上调一档，最小 11px（正文 13px）。
- 对比度：17 处低于 4.5:1 的灰色文字加深到 `#5e6982` / `#57627a`。
- 卡片：统一圆角 14–16px、白色细边、分层阴影，可点击卡片悬停微浮。
- 去掉英文小标签（ENTITY INSPECTOR、MODEL STUDIO、EVIDENCE EXPLORER 等），改用中文短标签或删除。
- 管网：管线更粗更深，节点更大并带白描边，故障点改为红色标记和标签。
- 时间轴：加预运行斜纹、故障时段红色底纹、处置动作刻度，滑块更大。

## 四、动效

全部在 150–900ms，缓出曲线，不弹跳；系统开启「减少动画」时全部关闭（沿用 GPT 的全局规则）。

| 动效 | 表达的含义 |
|---|---|
| 切页淡入（从半透明起步，动画暂停时内容也可见） | 页面切换 |
| 导航指示条滑动 | 当前所在页面 |
| 指标数字滚动（终值永远是接口数值） | 切换方案时差值有多大 |
| 五层准入依次亮起 | 逐层验收 |
| 故障点脉冲 | 故障正在发生 |
| 流向光带（示意） | 流向与相对流量 |
| 节点颜色过渡、选中节点弹出 | 时刻变化、当前选中 |
| 管网缩放过渡、卡片悬停微浮、弹窗缩放淡入 | 操作反馈 |

## 六、没有验证的部分
