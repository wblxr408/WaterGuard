# 模型接入与 AGH 的职责

2026-10-05：以用户重新核对的赛事要求为准，必须使用 AGH 完成核心任务的组织、执行或工具调用；模型可以选择，成果展示使用 WaterGuard 自有界面。

AGH 是执行基座，模型在 AGH 中理解任务、规划并读取反馈；WaterGuard 插件提供专业工具，Python 后端执行真实水力计算、冻结约束和独立验证。

## 在 WaterGuard 中配置

打开 [WaterGuard](http://127.0.0.1:5173/) 的“智能体”页，点击“模型账号”。选择提供商和账号对应地址，在本机输入 Key，测试连接，选择返回目录中的模型 ID，再保存。默认继续使用赛事 Agnes；更换账号不会让既有运行暗中切换模型。启动步骤见 [前后端启动与接入](前后端启动与接入.md)。

| 模型 | AGH Provider ID | API 地址 |
|---|---|---|
| 赛事 Agnes | `agnes-ai` | `https://api.agnes-ai.cn/v1` |
| DeepSeek | `deepseek` | `https://api.deepseek.com` |
| 国内智谱 GLM 普通 API | `zai` | `https://open.bigmodel.cn/api/paas/v4` |
| 国内智谱 GLM Coding Plan | `zai` | `https://open.bigmodel.cn/api/coding/paas/v4` |
| 国际 Z.ai GLM 普通 API | `zai` | `https://api.z.ai/api/paas/v4` |
| 国际 Z.ai GLM Coding Plan | `zai` | `https://api.z.ai/api/coding/paas/v4` |

GLM 的 Key、区域和账号套餐需要与 API 地址一致。模型使用 AGH 实际返回的账号目录，不凭文档里的品牌名称推定可用模型。

## 官方文档核对

仓库 [快速开始](../vendor/agnes-harness/docs/guide/quickstart.zh-CN.md) 要求测试连接、选择目录模型再保存；[配置参考](../vendor/agnes-harness/docs/reference/configuration.zh-CN.md) 要求配置与凭据分离，通过配置服务管理账号。

本项目使用独立 `AGH_HOME=D:/WaterGuard/.cache/agh-waterguard` 和 `local-dev` profile。Key 通过 SDK 配置服务提交，不写入 YAML、命令参数、应用运行报告或浏览器本地存储。官方 Web 设置页也可配置，但不是作品任务入口的必要条件。

Agnes 适配源码说明中国与国际网关分别认证，目前内置适配使用中国地址。此前账号测试返回 401；2026-10-06 用户提供新凭据后，官方配置服务认证通过并保存为本机默认账号，实际账号目录返回 `agnes-3.0-flash`。通过新版前端代理，在不重新输入 Key 的情况下测试连接和保存均通过。目录显示模型不等于认证成功；本次以官方 `verified=true` 和保存后复测为依据，模型驱动的水力 Live 闭环仍需单独验收。

测试和保存会引用同一 AGH 账号；未显式指定账号时，仅复用提供商和 API 地址相同的已启用账号，优先当前默认账号。地址变更时需要对应凭据，多账号无法唯一确定时须明确选择。

## 自有界面的执行路径

WaterGuard 工作台 → FastAPI → 官方 Node SDK → AGH 会话与模型循环 → 原生 WaterGuard 工具 → 水力计算与独立验证 → AGH 原生事件和结果 → WaterGuard 工作台。

`scripts/agh_bridge.mjs` 使用官方 SDK 的配置、会话、模型选择、prompt 和事件接口。`services/api/agh.py` 管理进程与运行生命周期，不另行调用模型 API 组织智能决策。

Live 路径必须取得有效账号、实际会话和工具调用记录后验证。Benchmark 是独立的水力工具验收。DeepSeek、GLM 尚未提供凭据，因此当前只验证接入配置能力，不声称已完成付费 API 调用或模型驱动的水力闭环。

官方提供商参考：[DeepSeek](https://api-docs.deepseek.com/api/deepseek-api/)、[智谱 OpenAI 兼容接口](https://docs.bigmodel.cn/cn/guide/develop/openai/introduction)、[智谱 Coding Plan](https://docs.bigmodel.cn/cn/coding-plan/quick-start)。
