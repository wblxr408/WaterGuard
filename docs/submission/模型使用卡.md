| 项目 | 实际使用情况 |
|---|---|
| Provider / 模型ID | `agnes-ai` / `agnes-3.0-flash`；这是提供商返回的标识，未获得更细内部权重版本 |
| 主案例 | `run-9823e888d98e43fa972dfaa12bc4d517`，2026-10-12 |
| 执行成本 | 39次实际模型调用、8次实际仿真、父运行墙钟601.969秒；完整原生会话599.237秒 |
| 模型职责 | 读取冻结任务和拓扑，选择候选，读独立反馈，诊断失败、申请动作修订、比较和解释结果 |
| 外部工具 | 任务、网络、候选、提交、仿真、验证、诊断、修订、比较、证据工具；原生事件保存真实请求与结果 |
| 受控边界 | 模型不能降低冻结阈值、扩大设施权限、回填动作时刻或自报验证通过；335/330越权修订被真实拒绝后模型纠正 |
| 正式交付 | BEST_EFFORT_MITIGATION；备用泵10在5400秒开启；`selected_candidate_id=null`，保留违规 |
| 核查入口 | 证据包内`evidence/latest-live/agh/native/events.jsonl`、`agh/model.json`、`agh/probe.json`、任务、计划与独立验证报告 |

推荐判定来自独立验证器和宿主准入。WNTR/EPANET完成数值求解，候选生成器提供有限可执行搜索起点，模型贡献不等同于独立计算水力结果。最差节点、平均节点、缺水与动作成本依次排序，仅描述已测集合。

Jev为可选路由接口，主案例未配置其账号，工具返回未连接；本作品不把这一接口记为已验证模型能力。DeepSeek/GLM接入配置属于可选能力，不作为上述主案例的实测模型。GPT与Claude是团队确认使用的开发辅助工具，不替代正式AGH原生执行证据。

追加同计划+10%复验在原任务与原计划下执行真实物理benchmark，单独存档；它不属于原Live的39次模型调用或8次仿真。重复对照、消融和预算分支各自记录模型ID、实际调用、墙钟与原始证据，见[证据索引](证据索引.md)。
