## 完整包便携安装

最新完整ZIP含两段视频、Windows x64便携安装包和测试样例，按[完整包运行说明](完整包运行说明.md)可离线回看既有运行。以下源码安装用于开发和主动新实验。

## 安装

从仓库获取源码时执行`git submodule update --init --recursive`。赛事源码ZIP含官方AGH源码快照，不需要另找最新主分支替换。进入源码根目录：

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r services/api/requirements.txt -r services/hydraulics/requirements.txt
cd apps/web-gpt
npm.cmd ci
cd ../../vendor/agnes-harness
pnpm install --frozen-lockfile
# Windows准备Node头文件与官方原生模块，按官方脚本完成本机构建
.github/scripts/prepare-windows-native.ps1 -CacheRoot "$env:LOCALAPPDATA/node-gyp/Cache"
pnpm --filter @agnes/system-node build:native
pnpm --filter @agnes/cli build:local
cd ../..
```

## 分别保持三个终端运行

以下直接启动三个实际服务，不执行健康探针或旧验收入口：

```powershell
# 终端一：源码根目录
.venv/Scripts/python.exe -m uvicorn services.api.main:app --host 127.0.0.1 --port 8010

# 终端二：源码根目录；先按官方要求构建AGH
$env:AGH_HOME = "$PWD/.cache/agh-waterguard"
$env:AGNES_PROFILE = 'local-dev'
$env:WG_API_URL = 'http://127.0.0.1:8010'
node vendor/agnes-harness/packages/cli/dist/local/agnes.mjs serve --profile local-dev --cwd "$PWD" --data-dir "$PWD/.cache/agh-waterguard/data" --port 4180

# 终端三：apps/web-gpt
npm.cmd run dev -- --host 127.0.0.1 --port 5173
```

在源码根目录，用官方SDK安装/信任业务插件：`node --import ./vendor/agnes-harness/node_modules/tsx/dist/loader.mjs scripts/configure_agh.mjs`。打开工作台`http://127.0.0.1:5173/`，在“智能体→模型账号”使用自己的账号测试并保存实际可用模型，Key不写入参赛材料。

$env:WG_ARTIFACT_ROOT = (Resolve-Path ../demo/artifacts).Path
$env:WG_DATABASE = (Resolve-Path ../demo/artifacts/waterguard.sqlite3).Path
.venv/Scripts/python.exe -m uvicorn services.api.main:app --host 127.0.0.1 --port 8010
