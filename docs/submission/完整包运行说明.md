# 完整提交包运行说明

完整ZIP包含五类交付：source代码（含官方AGH固定源码）、installer安装包、submission说明、videos两段演示、test-samples测试样例；demo为实际运行数据库，evidence为历史原始证据。

## Windows x64便携安装

将完整ZIP解压到同一目录，再将installer/WaterGuard-Windows-x64.zip解压到该目录，得到installer/runtime和installer/web。安装包已包含Python3.12、Node、Python依赖和构建后的前端，不需要另装Python或Node，不需要在线安装依赖。安装包与外层source、demo配套使用，不覆盖已有数据库。首次运行不启动新模型会话或求解。

在解压目录打开PowerShell，保持两个终端运行。

终端一：

```powershell
$env:WG_ARTIFACT_ROOT = (Resolve-Path ./demo/artifacts).Path
$env:WG_DATABASE = (Resolve-Path ./demo/artifacts/waterguard.sqlite3).Path
cd source
../installer/runtime/python/python.exe -m uvicorn services.api.main:app --host 127.0.0.1 --port 8010
```

终端二：在解压目录执行：

```powershell
cd installer/web
../runtime/node.exe node_modules/vite/bin/vite.js preview --host 127.0.0.1 --port 5173
```

浏览器打开：http://127.0.0.1:5173/?run=run-efda67724ab043ccaf9a49a30373f161&page=compare

回看已有结果无需模型账号。模型账号页面以及新建Live任务需按source/docs/submission/复现与运行.md另行构建并配置官方AGH；便携包交付历史回看和现有API/水力依赖，不预置团队账号。关闭两个终端即可结束运行。
