## 运行方法

先解压本包，再将installer/WaterGuard-Windows-x64-slim.zip解压到本包根目录，得到installer/runtime、installer/web。保持两个PowerShell终端运行。

终端一（从包根目录）：

```powershell
$env:WG_ARTIFACT_ROOT = (Resolve-Path ./demo/artifacts).Path
$env:WG_DATABASE = (Resolve-Path ./demo/artifacts/waterguard.sqlite3).Path
cd source
../installer/runtime/python311/python.exe -m uvicorn services.api.main:app --host 127.0.0.1 --port 8010
```

终端二（从包根目录）：

```powershell
cd installer/web
../runtime/node.exe node_modules/vite/bin/vite.js preview --host 127.0.0.1 --port 5173
```
