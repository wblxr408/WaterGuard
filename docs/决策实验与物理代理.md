# 决策实验与物理代理

## 入口

前端增加“决策实验”，也可通过 `http://127.0.0.1:5173/?page=lab` 进入。可带入工作台所选候选，或点击“载入情景任务”，复用现有任务创建、设施目录和候选生成接口。

这次交付按用户最后要求只完成代码，不执行新增验证、构建、浏览器操作或 GNN 训练。此前非 GNN 版本留下的实验记录不是本次 PyG 版本的验证结果。

## 三类研究

1. **失效边界**：输入需求倍率、抢修完成时刻及总预算。精验结果分为正常层达标、基本供水达标、存在缺口和计算无效；没有精验的点保留未知。点击地图点查看指标、首次失败区间和验证报告。
2. **最小补救**：为提前抢修或增加设施操作声明同一口径的成本分值，系统重算原方案与补救选项，从已测试达标项选择最低成本。新增操作仅用于独立假设任务，不修改源任务授权。
3. **事件重评**：输入抢修事件时刻、响应延迟和新的抢修完成时刻。事件前动作保留，从原始状态重放历史；新动作不早于响应时间下限。根据事件后剩余时段的指标及原任务冻结目标排序选择已测计划。

## Physics-informed GNN

直接复用开源 PyTorch Geometric 的 `GCNConv`，两层32通道图卷积加一层残差输出。此库提供图卷积组件，WaterGuard 负责组装本领域输入、损失及粗精配对学习；没有附带声称已训练好的供水模型权重。

输入为粗解节点压力、节点高程、基础需求、管网度数、需求倍率及1.852次特征、故障持续时间。边权来自管道长度、直径和粗糙度的 Hazen–Williams 关系。学习目标是粗精配对节点压力残差，损失包含压力拟合、PDD供水关系和图上残差平滑。这里没有新增完整水力方程求解网络，真正的水力守恒仍由原有求解器处理。

至少两个粗精配对样本后更新模型。预测不确定度采用 MC Dropout 离散程度与训练残差，只作下一次复验的排序量。研究产物保存代理元数据、复验前预测误差和 `surrogate.pt` 权重。

依赖声明在 `services/hydraulics/requirements-surrogate.txt`，本次仅新增依赖文件，未安装或运行。需要启用 GNN 时在现有环境安装：

```powershell
.\.venv\Scripts\python.exe -m pip install -r services/hydraulics/requirements-surrogate.txt
```

库依据：[PyG GCNConv](https://pytorch-geometric.readthedocs.io/en/latest/generated/torch_geometric.nn.conv.GCNConv.html)、[PyG 安装说明](https://pytorch-geometric.readthedocs.io/en/latest/install/installation.html)。

## 多保真流程

粗层使用较大的水力步长（报告步长）；精层保留源任务水力配置。两层均复用 PhysicalAdapter 与独立验证。先使用部分预算粗筛分散情景，再以 GNN 预测的约束裕量和经验不确定度选择精验点。粗解、预测和精验结果分字段保存；只有精验结果进入地图达标状态。

总次数包括粗层和精层，用户可指定高精度配额。实际计算时间和采样误差作为研究结果记录；代码不预设加速倍数或收益。

## API

- `POST /api/decision-studies/preview`：构造研究输入，不启动求解。
- `POST /api/decision-studies`：启动独立研究。
- `GET /api/decision-studies`：读取最近研究。
- `GET /api/decision-studies/{study_id}`：进度与点级详情。
- `POST /api/decision-studies/{study_id}/cancel`：取消计算，保留已完成点。

请求包含 `task`、`plan`、`kind` 和预算。边界模式可设置 `use_surrogate=true` 与 `high_fidelity_budget`；补救模式传 `rescue_options`；事件模式传 `event_time_s`、`response_time_s` 和 `new_repair_end_s`。具体字段由 services/api/decision_studies.py 的 StudyRequest 定义。

原子 JSON、线程执行、取消以及仿真进程均复用既有实现。研究保存在 `artifacts/decision-studies/`，不写入源运行的正式推荐。
