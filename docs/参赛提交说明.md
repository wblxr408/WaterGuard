## 核心方法与模型使用

AGH 使用仓库固定的官方 Agnes Harness 子模块，通过官方 Node SDK 建立实际会话。模型使用保存的赛事 Agnes 账号，实际名称、版本标识及调用时间以每次 `agh/probe.json` 和原生 trace 为准；本轮预选 `agnes-3.0-flash`。使用环节为任务理解、候选选择、工具调用、反馈调整和结果解释。模型不计算或写入验证通过标志，不修改用户冻结的阈值。

WNTR 1.5.0 / EPANET 进行扩展周期水力求解。实际依赖版本与原生库 SHA-256 保存在各仿真的 `environment.json`。独立验证器重算业务指标，AGH 宿主汇总同一候选的名义与必需压力复验，原生工具与应用事件进行关联。

Jev 是可选辅助路由能力。目前没有已验证的提供商账号调用证据时，应明确展示未连接状态；它不作为核心 AGH/水力成果的已完成证据。

## 运行和验证

按 [仓库说明](../README.md)、[公共契约安装说明](../packages/contracts/README.md) 和 [官方 AGH 启动说明](AGH基座与启动.md) 安装依赖。Windows 的验收命令：

```powershell
.venv/Scripts/python.exe scripts/start_agh.py
npm run start:fullstack
.venv/Scripts/python.exe scripts/contest_acceptance.py --output artifacts/new-acceptance
.venv/Scripts/python.exe experiments/scenario_lab.py --summary artifacts/new-acceptance/summary.json --output artifacts/new-scenario-lab
```

分别在终端保持 AGH/API 与前端运行。工作台为 `http://127.0.0.1:5173/`，AGH 检查页为 `http://127.0.0.1:4180/`。完整运行依赖有效的模型配置；Fixture、离线数值基准与模拟 SDK 测试不能代替 Live 原生证据。

本轮验收汇总 `artifacts/contest-acceptance-v4/summary.json` 冻结代码哈希、任务、模型、实际工具顺序、验证指标、ZIP 哈希与同预算对照。六个真实场景均通过预定验收，95 次模型调用、15 次仿真、每个子报告独立重算。录制与演示加载其中同一运行 ID，通过 `?run=<run-id>&page=compare` 进入实际记录。工程失败和边界场景如实展示不可推荐。

最后新增的运行深链接加载与证据中心 ZIP 下载已按实际六个页面和下载文件复核，161 个其他核心执行文件保持冻结哈希；该页面差异的原始和最终 SHA-256、完整观察与下载文件见 `artifacts/contest-ui-revalidation/verification.json`。本地下载 ZIP 逐条内容与验收包相同，容器时间戳可能不同。

190 项自动检查的实际结果为 188 通过、2 个 Windows 平台跳过；另有六场景 Live、26 项实际物理研究、六个浏览器页面、ZIP 下载和 60 秒实际预算耗尽证据。详细事实和数值边界见逐项分析。

最终源码与技术证据包为 `artifacts/WaterGuard-contest-submission.zip`，包内清单和同名 `.receipt.json` 提供实际哈希。未填写、未签署的队伍资料明确列为待办，技术就绪不自动表示已经正式提交。

## 4 分钟实际操作视频脚本

| 时间 | 操作与画面 | 必须可核查的内容 |
|---|---|---|
| 0:00–0:35 | 工作台打开正常运行；展示任务、网络来源和冻结阈值 | 真实问题、数据来源、目标、运行 ID |
| 0:35–1:25 | 智能体页查看实际调用顺序和日志；打开已完成工具反馈 | 原生 AGH/模型参与；真实外部仿真；名义和需求 +10% 实算 |
| 1:25–2:15 | 打开 Net3 工程失败运行；对照基线和动作候选 | 具体违规；模型读取反馈；实际泵动作；缺供变化；仍低压则拒绝推荐 |
| 2:15–2:50 | 打开受控非法动作和严重边界记录 | `INVALID_ACTION` 后合法调用；没有非法仿真；边界的物理成功与业务失败 |
| 2:50–3:35 | 方案页查看五层准入、原始指标和具体违规区间 | 正式验收使用内部时刻；曲线公共采样说明；候选与父结论一致 |
| 3:35–4:00 | 证据中心打开原始验证报告并导出 ZIP | 原生 trace、任务/计划/原始数据/报告/哈希；复现命令与模型边界 |
