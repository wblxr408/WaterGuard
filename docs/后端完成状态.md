# WaterGuard 后端完成状态

更新日期：2026-10-06

本文记录“同学 2：AGH、后端与运行治理”当前可复现实装状态，避免把本地基准仿真误写成已经完成的真实 AGH 比赛闭环。

## 已完成并验证

- FastAPI、SQLite 元数据、JSONL 运行事件及 artifacts 存储。
- 任务版本、`constraint_hash`、幂等键、状态机和模拟预算预留/结算。
- 严格 MCP 网关模式：AGH 主机提供会话与角色；工具按服务端 `run_id` 读取冻结任务，拒绝模型提交的任务快照。
- 角色权限、候选枚举、动作计划预检、物理网络目录与物理 0.3/0.4 任务入口。
- 进程隔离的 WNTR/EPANET 物理仿真、取消、持久化作业、网关重启后的遗留作业归档及预算结算。
- 有界需求扰动真实进入物理计算；输入哈希、`perturbation_id`、输入清单、实体映射与独立验证均绑定该扰动。
- 独立验证器、Pareto 非支配比较、候选数量上限校验。
- 证据包哈希清单；只有非空 AGH 原始记录、匹配的会话、应用事件↔原生工具调用关联和模型配置引用齐全时才允许 live 导出。

## 已验证方式

- `python -m unittest discover -s services -p 'test_*.py'`：20/20 通过。
- `python packages/contracts/scripts/check.py`：通过 Schema、哈希、事件顺序、来源和独立指标复算校验。
- 需求倍率 1.1 的扰动测试实际运行 WNTR，确认物理产物和复验报告均绑定扰动参数。
