## 明确延期的部署能力

- 可信的多子代理身份隔离；比赛版使用单个受限 AGH 会话分阶段执行。
- 多用户持久队列、跨机器任务接管、Windows Job/Object 或容器级资源隔离。
- 大规模留出场景评测和固定搜索/单代理/多代理的同预算效果对照。

整合后同时保留原生 SDK 和严格 MCP 网关的会话、预算及作业接口。SDK 关联文件包含实际应用事件 ID 和原生工具引用，与证据服务的最小来源校验格式一致；ZIP 导出仍核对文件哈希。模拟 SDK 回归用于核对接口兼容性，不作为真实 Live 验收证据。

扰动参数在分配作业前校验并冻结；完整物理编译仍在隔离 worker 中执行，使非法引擎等物理失败保留诊断和证据。
