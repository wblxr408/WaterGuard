# Agnes 实时运行与 Jev 接入

2026-10-06：工作台和智能体页默认新建 Agnes Live 任务。执行过程由官方 AGH SDK 会话组织，WaterGuard 原生工具提供中国管网读取、候选选择、真实 WNTR 仿真与独立验证。工作台通过持久化 SSE 跟随同一个 run_id，每个验证完成的候选立即驱动三维拓扑、节点压力、供需比、管段流量与时间轴。

## 会话与数据绑定

`scripts/agh_bridge.mjs` 使用 `setModel({slot:'primary', ...})`，并为每个运行传入 `sessionKey: waterguard:<run_id>`。SDK 未指定 sessionKey 时会复用工作区会话，而 `session.events()` 会重放历史；复用会使旧工具结果混入新任务。独立会话避免该问题，所有候选、仿真和报告仍核对冻结的 task_ref。

`services/api/agh.py` 在真实工具开始时更新阶段，在原生 `request/sent` 时计数模型请求；进度快照直接进入 SSE 的 run 通道，不为每次更新另造 run.started 工作流事件。验证后发布候选 JSON。工作台读取子运行的物理检查与实体映射，不复制 series 文件到父运行，保持 simulation_id 的全局唯一查找。

## Jev

官方 [AGH 架构说明](https://github.com/AgnesAI-Labs/agnes-harness/blob/main/docs/develop/architecture.md) 将 Jev“小脑”列为目标架构，目前主分支未提供原生 Jev 适配。本项目在业务插件增加 `wg_jev_decide`，调用 [TypeSafe 结构化 API](https://docs.typesafe.ai/api)：`POST https://api.typesafe.ai/v1/systemone`，模型 `jev-latest`。choice 返回下一候选、概率分布和置信度；noul 判断当前验证结果的未解决风险。

输入来自服务端冻结任务、候选动作、真实验证报告和剩余模拟预算，模型不能随意提交替代状态。Jev 建议交给 Agnes 继续规划，独立验证保持原有职责。决策 JSON 存在当前 run 的 jev 目录，面板通过实际 jev.completed 日志更新，保留模型名称和耗时。

工作台及智能体页提供“Jev 决策中枢 → 配置 Jev”。通过真实连接验证后，将 TypeSafe Key 保存到本机被忽略的 `.cache/jev/credentials.json`；也可用 `TYPESAFE_API_KEY`。接口不返回 Key，凭据不进入运行证据。用户目前没有 Jev Key，并明确先完成 Agnes；此时工具返回 configured=false，面板显示待连接，不生成概率或风险数值。实际 TypeSafe 付费调用尚未验收。

## 本次执行与标准流程

2026-10-06：智能体页默认显示“本次执行”。`agent-execution.ts` 按原生 `toolUseId` 生成独立调用节点，开始和返回配对；重复订阅按事件 ID 去重。没有发生的工具调用不会出现在图中。`wg_get_task`、`wg_inspect_network`、`wg_generate_candidates`、两次独立的 `wg_jev_decide`、方案提交、仿真与验收保持真实顺序。未知的后续 `wg_` 工具也能生成节点。

`GET /api/runs/{run_id}/execution` 从已存的原生 projection 重建历史，返回工具名、原生调用号、候选/父候选/子运行关联、时间和受限结果摘要。候选返回与 `plan_json` 只公开候选关联和动作的 kind/link_id/simulation_time_s，验收报告只公开准入状态、有限指标和违规条数；不向前端传模型文字、原始参数、凭据或完整工具结果。新调用通过持久化 SSE 的 info.execution 直接更新；历史读取和 SSE 使用相同投影函数。

不同候选的再次提交自动展开切换方案分支；如果存在 parent_candidate_id，指向对应父方案并标记修改方案。失败调用之后相同工具和候选的再次调用展开重试分支。分支出现需真实的后续调用，验收未达标本身不等于已经修改。普通灰色连线表示调用顺序；橙色虚线表示候选关联或失败后的重试，并不将并发调用的排序当作因果关系。

执行结束来自运行事件，证据归档来自实际 evidence-manifest，工程验收结论单独显示。回放逐条展示真实开始/返回，暂停和拖动进度条不会提前显示后面的节点。支持调用详情、调用编号、耗时、跟随展开和窄屏列表。固定的分支导图、流程总览移至“标准流程”，作为参考，不再叠加推测的执行状态。
