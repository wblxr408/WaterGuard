# 前后端启动与接入

2026-10-04：现有二维 HTML 工作台已接入 FastAPI。页面与 API 由同一服务提供，地址为 http://127.0.0.1:8000/。

## 启动

Windows PowerShell：

```powershell
cd D:\WaterGuard
npm start
```

启动器优先使用项目 `.venv`，无需激活环境。也可以双击 `scripts/start_waterguard.cmd`，或直接运行：

```powershell
.\.venv\Scripts\python.exe -m uvicorn services.api.main:app --reload --host 127.0.0.1 --port 8000
```

浏览器访问 [工作台](http://127.0.0.1:8000/)；[接口文档](http://127.0.0.1:8000/docs)；[健康检查](http://127.0.0.1:8000/healthz)。关闭服务按 Ctrl+C。已经启动了带 `--reload` 的同一服务时，修改后端会自动加载，刷新页面加载新的 JS/CSS；无需再启动第二个服务。

换端口使用 `npm start -- 8001`，也可执行 `.\.venv\Scripts\python.exe scripts/start_workbench.py --port 8001`。页面内请求采用相对路径，会连接页面所在的端口。直接打开 HTML 文件会跳转到默认 8000 地址。

新环境先创建 Python 3.11 环境并安装两组依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r services/api/requirements.txt -r services/hydraulics/requirements.txt
```

## 页面操作

1. 选择 EPA Net1 或 Net3、正常/关闭/泄漏/断裂工况和故障管段。
2. 输入全部用户节点的压力、供需比要求，以及最多候选数。默认 3 个，包含零动作基线。
3. 保持 Benchmark 模式，点击“创建任务并运行”。任务在后端生成、计算哈希并保存；随后后台运行真实 PhysicalAdapter 独立进程。
4. 切换候选，地图、指标、动作、独立校验和原始压力曲线联动。拖动时间轴查看报告时间点；点击违规项定位节点与时间。
5. 从“方案与证据”查看比较表、缺项和下载证据清单 JSON；原始计算文件保存在 `artifacts/<run_id>/simulations/`。
6. 运行中可取消；历史选择器读取服务端最近 20 条记录。刷新页面会恢复该浏览器上次选择的运行。

默认时间设置：0–3 小时仿真，0–1 小时预热，1–2 小时故障，1–3 小时评估；报告步长 900 s，水力内部步长 300 s。泄漏面积采用预设 0.0005 m²，流量系数 0.75；断裂采用已有双端物理映射。全部参数、来源假设和哈希可在记录字段中核对。

## 接口与执行边界

| 接口 | 用途 |
|---|---|
| `GET /`、`/assets/*` | 工作台与静态资源 |
| `GET /api/networks/{id}` | 源模型拓扑、目录、可故障管段 |
| `POST /api/tasks/from-proposal` | 接收页面参数，在 Python 内冻结并保存 TaskSpec |
| `POST /api/task-proposals` | 只预览规范 TaskSpec |
| `GET /api/tasks/{id}` | 读取指定冻结任务版本 |
| `POST /api/tasks/{id}/runs` | 创建运行；Benchmark 0.4.0 自动执行 |
| `GET /api/runs` | 最近运行 |
| `GET /api/runs/{id}/results` | 候选、仿真摘要、独立校验 |
| `GET /api/runs/{id}/error` | 真实失败原因 |
| `GET /api/runs/{id}/events` | SSE 格式的增量事件；当前前端周期读取有限事件批次，使用 Last-Event-ID 去重续读 |
| `GET /api/simulations/{id}/series` | 原始报告时间点时序 |
| `POST /api/runs/{id}/cancel` | 取消运行并传递到 PhysicalAdapter 进程监督器 |
| `GET /api/runs/{id}/evidence` | 含哈希与缺项的证据清单 |

Benchmark 固定枚举零动作及单动作候选，按目录顺序选择最多 6 个；不承诺改善或穷尽搜索。源控制冲突和故障管段不进入自动动作目录。运行完成仅表示名义比较结束；必要扰动复验仍 pending，conclusion 保留 INCOMPLETE，推荐准入依照独立报告显示。

Live 请求仍由后端明确返回 `503 AGH_UNAVAILABLE`，目前的页面接入不会将 Benchmark 显示为 Agnes 决策。AGH 宿主、真实模型调用、原生记录和复验闭环仍需后续实现。

执行器支持两个并发后台运行，SQLite 保留状态。开发服务重载或退出会取消正在监督的计算；异常重启后未结束的 Benchmark 会记为 ERROR / SERVER_RESTARTED，需创建新运行。此版本面向单 API 进程的本地工作台，不使用多个 Uvicorn worker 共享同一数据库执行任务。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s services/api/tests -v
node --check design/workbench.js
```

API 回归包括真实 Net1 关闭与 Net3 断裂计算、时序与证据读取、幂等启动、取消信号传递、异常和重启记录、服务器端冻结哈希，以及候选限额。浏览器验证覆盖创建运行、候选切换、比较与证据、取消和页面恢复。
